🎙️ GIN-Voice [v057]

Мгновенный голосовой ввод и умная AI-диктовка на базе Whisper Large v3 для Windows 10/11

1
Быстрый старт: Как получить ключ Groq API

GIN-Voice использует бесплатный сверхбыстрый облачный движок Whisper Large v3 (скорость распознавания до 300+ слов в секунду):

  • Перейдите в консоль Groq Cloud по ссылке ниже.
  • Войдите через Google или GitHub аккаунт.
  • Нажмите Create API Key, скопируйте ключ вида gsk_....
  • Вставьте его в поле настройки GIN-Voice и нажмите 💾 Сохранить и Применить.
🔑 Получить бесплатный Groq API Key ↗
2
Управление диктовкой (Горячая клавиша F4)
  • Поставьте курсор в любое место: Браузер, редактор кода, Word, Telegram, WhatsApp, командная строка.
  • Нажмите F4: Прозвучит мягкий приятный звуковой сигнал, иконка в трее возле часов станет красной (мигающий индикатор).
  • Говорите свободно: Диктуйте мысль на русском, английском, чешском или любом из 18 поддерживаемых языков.
  • Нажмите F4 повторно: Запись завершится, нейросеть за доли секунды распознает речь и мгновенно вставит готовый текст прямо у вашего курсора!
  • Режим Push-To-Talk: Вы также можете просто зажать F4, сказать фразу и отпустить клавишу — текст сразу же напечатается.
3
Чистый интерфейс без помех экрану
  • Никаких перекрывающих оверлеев: Вся визуальная индикация сосредоточена в системном трее (красный микрофон при записи, синий спиннер при распознавании). Верхняя область экрана и вкладки браузера всегда на 100% свободны.
  • Информативная подсказка: При наведении мыши на иконку возле часов вы всегда видите статус, горячую клавишу и точную версию программы.
  • История диктовок: Правый клик по иконке в трее открывает последние 7 диктовок для быстрого копирования любого ранее сказанного текста.
  • Папка программы и удаление: В меню есть пункт «📂 Открыть папку программы», где находится красивый деинсталлятор Uninstall.exe для чистого удаления в один клик.

Ultra-Fast Voice Typing & AI Dictation with Whisper Large v3 for Windows 10/11

1
Quick Start: Get Your Free Groq API Key

GIN-Voice utilizes the ultra-fast Whisper Large v3 model (processing speech at 300+ words per second):

  • Open the Groq Cloud console using the button below.
  • Sign in with your Google or GitHub account.
  • Click Create API Key and copy your key starting with gsk_....
  • Paste it into GIN-Voice settings and click 💾 Save & Apply.
🔑 Get Free Groq API Key ↗
2
How to Use (Single F4 Hotkey)
  • Place your cursor anywhere: Browser, text editor, IDE, Word, Telegram, Chat.
  • Press F4: A soft chime sounds and the tray icon turns into a pulsing red recording indicator.
  • Speak naturally: Dictate in English, Russian, Czech, or any of the 18 supported languages.
  • Press F4 again: Recording stops, Whisper AI transcribes your voice in milliseconds, and pastes the text directly at your cursor!
  • Push-To-Talk Mode: You can also hold F4 while speaking and release it to finish.
3
Zero Screen Obstruction & Tray Control
  • No intrusive overlays: All state indication lives cleanly in your system tray without blocking your browser tabs or toolbar buttons.
  • Rich Tooltip: Hovering over the tray icon displays current status, hotkey, and exact version.
  • Dictation History: Right-click the tray icon to access your last 7 dictations with one-click clipboard copying.
  • Clean Management: Right-click menu includes "📂 Open Program Folder" where a dedicated Uninstall.exe allows complete removal at any time.

Rychlý start: Získejte bezplatný klíč Groq API

GIN-Voice využívá extrémně rychlý cloudový engine Whisper Large v3 (přepis rychlostí přes 300 slov za sekundu):

  • Otevřete konzoli Groq Cloud pomocí odkazu níže.

🔑 Získat bezplatný Groq API Key ↗
2
Jak používat (Klávesová zkratka F4)
  • Umístěte kurzor kamkoliv: Webový prohlížeč, editor kódu, Word, Telegram nebo formulář.
  • Stiskněte F4: Ozve se jemný zvukový tón a ikona v liště začne červeně blikat.
  • Mluvte přirozeně: Diktujte česky, anglicky, rusky nebo v jakémkoliv z 18 podporovaných jazyků.
  • Stiskněte F4 znovu: Nahrávání se ukončí a rozpoznaný text se během zlomku vteřiny vloží přímo na pozici kurzoru!
  • Režim Push-To-Talk: Můžete také klávesu F4 pouze podržet během mluvení a uvolnit pro okamžité vložení.
3
Čisté rozhraní a ovládání v systémové liště
  • Žádná překážející okna na obrazovce: Veškerá indikace je decentně integrována do ikony v liště, takže vaše záložky a tlačítka v prohlížeči zůstávají vždy volné.
  • Informační nápověda: Po najetí myší na ikonu v liště se zobrazí stav, zkratka i verze aplikace.
  • Historie diktátů: Pravým tlačítkem myši otevřete menu s posledními 7 diktáty pro snadné opětovné zkopírování.
  • Složka a odinstalace: V menu najdete položku „📂 Otevřít složku programu“, kde je k dispozici přehledný Uninstall.exe pro kompletní odinstalaci na jedno kliknutí.
