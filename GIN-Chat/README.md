## 🌟 Ключевые Преимущества и Архитектура

<br/>

### 🛡️ 1. Сквозное E2EE-Шифрование (Zero-Knowledge Architecture)
* 🔐 **Криптография на клиенте:** Все текстовые сообщения и отправляемые файлы шифруются непосредственно на вашем устройстве (в браузере или приложении) с помощью стандарта **AES-256-GCM** через нативный **Web Crypto API**.
* 🚫 **Сервер ничего не знает:** Сервер выступает исключительно в роли слепого почтальона для зашифрованных пакетов. Даже при физическом доступе к серверу или базе данных прочитать переписку математически невозможно — приватные ключи хранятся только на устройствах собеседников.
* 🔒 **Защита персональных данных:** Номера телефонов, адреса электронной почты и системные идентификаторы скрыты от всех обычных участников диалогов.

<br/>

### 📞 2. Защищенные Голосовые и Видеозвонки (WebRTC)
* 🎙️ **Прямая P2P-связь:** Аудио- и видеоразговоры передаются напрямую между устройствами собеседников без промежуточного сохранения на сервере.
* 🛡️ **Криптографические протоколы DTLS 1.3 и SRTP:** Медиапотоки шифруются аппаратными алгоритмами защиты в режиме реального времени, исключая прослушивание, перехват или запись разговоров.
* ⚡ **Высокое качество и низкая задержка:** Автоматическая адаптация битрейта под скорость интернет-соединения, кристально чистый звук и HD-видео.

<br/>

### 🌍 3. Отдельный Выделенный Сервер без Блокировок
* 🚀 **Прямой выделенный канал:** Чат работает на автономном изолированном сервере в надежной юрисдикции с прямым DNS-маршрутом (без использования сторонних прокси-сетей и Cloudflare).
* 🌐 **100% Доступность 24/7:** Гарантированное мгновенное открытие и стабильная работа из **России, стран СНГ, Европы, Азии, Америки и любой точки мира** без необходимости использовать VPN.
* ⚡ **Высокая скорость:** Асинхронная архитектура на базе Node.js, SQLite с журналом опережающей записи (WAL) и Nginx с оптимизацией HTTP/2.

<br/>

### 📱 4. Кроссплатформенная Установка (PWA — Progressive Web App)
Устанавливается на любые устройства в один клик без необходимости скачивания из App Store или Google Play:

* 🖥️ **Windows Desktop (Chrome, Cent Browser, Edge, Brave):**
  * На экране входа и в главном меню доступна кнопка **«Установить GIN-Chat на устройство»**;
  * Открывается в отдельном чистом окне приложения без адресной строки и вкладок браузера, закрепляется на панели задач и в меню «Пуск».
* 📱 **Android Смартфоны и Планшеты (Chrome, Samsung Internet, Edge):**
  * Мгновенная установка через системный диалог добавления на домашний экран (WebAPK);
  * Нативный полноэкранный режим с поддержкой жестов и фонового кэширования интерфейса.
* 🍏 **Apple iOS / iPhone & iPad (Safari):**
  * Открыть ссылку на ваш сервер в Safari (например, `https://www.chat-xxxxxx.ru`);
  * Нажать иконку **«Поделиться»** ➔ выбрать **«На экран "Домой"»** (Add to Home Screen);
  * Запуск в изолированном окне с темной/светлой темой и кастомным статус-баром.

## 🚀 Быстрое Развертывание на Сервере за 1 Минуту

<br/>

### Требования к серверу:
* Linux-сервер (Ubuntu 22.04/24.04 LTS или Debian 11/12, архитектура `x86_64` или `ARM64`);
* Установленные Docker и Docker Compose (или Node.js 20+);
* Доменное имя или субдомен, направленный на IP-адрес сервера.

<br/>

### Шаг 1. Клонирование и запуск через Docker Compose

```bash
# 1. Склонировать репозиторий
git clone https://github.com/GinCz/GIN-Chat.git /opt/gin-chat
cd /opt/gin-chat

# 2. Запустить контейнер в фоновом режиме
docker-compose up -d --build

# 3. Проверить статус работы
docker-compose ps
```

<br/>

### Шаг 2. Конфигурация Nginx и выпуск SSL-сертификата

```nginx
server {
    listen 80;
    server_name www.chat-xxxxxx.ru;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name www.chat-xxxxxx.ru;

    ssl_certificate /etc/letsencrypt/live/www.chat-xxxxxx.ru/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/www.chat-xxxxxx.ru/privkey.pem;

    client_max_body_size 50M;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto https;
        proxy_read_timeout 86400s;
        proxy_send_timeout 86400s;
    }
}
```
