# 📌 Обязательные Правила для Windows EXE Приложений (Strict Windows Build & Versioning Protocol)

> **Статус:** Абсолютный регламент для всех Windows EXE проектов (GIN-NetScan, GIN-VPN и др.)  
> **Дата утверждения:** 05.10.2026  

---

## ⚡ 1. Любое изменение кода -> Новая версия (Auto-Bump Version)
- Любое изменение, исправление бага, оптимизация или добавление фичи в проект **ОБЯЗАТЕЛЬНО** влечет за собой увеличение номера версии (например, `v034` -> `v035`).
- Номер версии синхронно обновляется в:
  1. Константах приложения (`AppVersion = "v035"`, `AppTitle = "..._v035"`);
  2. Файле `version.txt`;
  3. Документации `README.md`;
  4. Записях реестра и установщике (`DisplayVersion`).

---

## ⚡ 2. Чистота репозиториев GitHub (Single Latest Binary)
- В публичном репозитории ([Windows_scripts ↗](https://github.com/GinCz/Windows_scripts)) и в приватном ([Secret_Privat ↗](https://github.com/GinCz/Secret_Privat)) **всегда хранится ровно один последний скомпилированный `.exe` бинарник**.
- Все предыдущие версии бинарников (`GIN-NetScan_v034.exe`, `v033.exe` и т.д.) **ОБЯЗАТЕЛЬНО удаляются из репозитория** (`git rm <old_binary>.exe`).
- Хранение старых бинарников в репозиториях строго запрещено.

---

## ⚡ 3. Автоматическая очистка и выгрузка на Рабочий Стол (MEGA Desktop Sync)
- При сборке новой версии агент **НЕМЕДЛЕННО И АВТОМАТИЧЕСКИ**:
  1. Удаляет предыдущую версию бинарника с Рабочего стола пользователя:
     ```bash
     mega-rm "/MEGA/DOCS/desktop/<old_binary>.exe" 2>/dev/null || true
     ```
  2. Загружает свежую версию бинарника в папку Рабочего стола (`D:\MEGA\DOCS\desktop` <-> `/MEGA/DOCS/desktop/`):
     ```bash
     mega-put -c "<path_to_new_binary.exe>" "/MEGA/DOCS/desktop/"
     ```
- На Рабочем столе пользователя должна оставаться **строго одна актуальная версия** исполняемого файла.
- Категорически запрещено оставлять дубликаты или старые версии.

## 🛑 Запреты
- ❌ **ЗАПРЕЩЕНО** вносить изменения в код без выпуска новой версии и нового билда.
- ❌ **ЗАПРЕЩЕНО** оставлять старые версии бинарников в GitHub или на Рабочем столе MEGA.
- ❌ **ЗАПРЕЩЕНО** завершать задачу без выгрузки свежего бинарника в `/MEGA/DOCS/desktop/`.
