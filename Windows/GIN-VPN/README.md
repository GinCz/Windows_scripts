# 🛡️ GIN-VPN by VladiMIR+AI (v016)

High-Speed Native Windows Xray/VLESS Reality VPN Client engineered with pure Go and Win32 API.

## 🚀 Features & Highlights
- **Single Monolithic Binary**: Zero external GUI frameworks or heavyweight runtimes. Pure Win32 API with native look & feel.
- **Embedded Shield & Dynamic Tray Icons**: Golden shield application icon + dynamic emerald green connection status icon in Windows System Tray.
- **Full-Featured Tray Context Menu**:
  - Open/Restore GUI window
  - 1-Click Disconnect / Connect
  - **Switch Server Node Submenu**: Instantly switch between 7 servers (IONOS-38, DE-222, RU-109, ORACLE-157, ORACLE-230, ALEX-51, STOLB-24) directly from the taskbar tray.
  - Quick IP & Speed verification portal
  - Fluent Day (Light) and OLED Night (Dark) mode toggles
- **True Tunnel Routing**: Integrates directly with the local Xray daemon on port `10809` (HTTP) and `10808` (SOCKS) + automatic Windows system proxy management with instant fallback to direct ISP routing on disconnect.
- **Dual-Mode 2-in-1**: Fully portable out of the box with built-in 1-click installer registering official Windows shortcuts and uninstaller.
- **Zero Scrollbars**: Responsive layout fitting all 7 VPN nodes simultaneously without horizontal or vertical clipping.
