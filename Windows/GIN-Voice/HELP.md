# 🎙️ GIN-Voice [v001] — User Guide & Personalization Help

> **Product:** GIN-Voice by VladiMIR+AI  
> **Target OS:** Windows 10 / 11 (64-bit)  
> **Engine:** Ultra-Fast Multilingual Speech AI (Whisper Large v3)  

---

## ⚡ 1. Быстрый старт (Quick Start)

1. **Горячая клавиша по умолчанию:** `[ F4 ]`
   * **Нажмите `F4` один раз** — прозвучит высокий звуковой сигнал (бип), и начнется запись с микрофона.
   * **Говорите** фразу на выбранных языках (поддерживается смешанная речь: русский, английский, чешский).
   * **Нажмите `F4` второй раз** — прозвучит завершающий сигнал. Аудио мгновенно расшифруется и **вставится прямо туда, где стоит ваш курсор** (в браузер, текстовый редактор, Antigravity, Telegram и т.д.).
2. **Иконка в трее (справа снизу у часов):**
   * Кликните **правой кнопкой мыши** по иконке микрофона `GIN-Voice` для доступа ко всем настройкам.

---

## 🌐 2. Выбор языков (Language Selection)

В меню трея доступен список языков с чекбоксами:
1. **English** — включен по умолчанию.
2. **Czech** — второй в списке (отметьте галочкой для чешской речи).
3. **Russian** — третий в списке (отметьте галочкой для русской речи).
4. Прочие языки (German, French, Spanish, Ukrainian).

> [!TIP]
> **Мультиязычный режим:** Если вы говорите по-русски и вставляете английские или чешские слова, включите галочки на всех используемых языках! Нейросеть Whisper Large v3 автоматически распознает переключение между языками на лету без ошибок.

---

## 📖 3. Персональный словарь (`dictionary.json`)

GIN-Voice автоматически заменяет произнесенные термины на точные имена ваших репозиториев и проектов!

Чтобы добавить новые слова:
1. В трее нажмите **Open Dictionary** (откроется файл `dictionary.json`).
2. Добавьте соответствие в формате:
   ```json
   {
     "джин синема": "GinCinema",
     "джин тв": "GinTV",
     "джин нетскан": "GinNetScan",
     "секрет приват": "Secret_Privat",
     "новое слово": "ПравильноеНаписание"
   }
   ```
3. Сохраните файл. Изменения подхватываются моментально!

---

## 📂 4. Привязка папки с базами знаний (Link AI Folder)

Вы можете автоматически наполнить словарь именами всех ваших репозиториев и проектов!
* Запустите команду из командной строки:
  ```cmd
  GIN-Voice.exe --link-folder "D:\AI\GitHub"
  ```
  или выберите **Link AI Knowledge Folder** в меню трея. Утилита просканирует каталоги и добавит все названия проектов в подсказки нейросети и словарь автозамены.

---

## 🔑 5. Настройка API ключа (Groq Whisper)

Для мгновенного распознавания за **0.3 секунды** используется бесплатный API Groq:
1. Получите бесплатный ключ за 1 минуту: [https://console.groq.com/keys ↗](https://console.groq.com/keys)
2. Откройте в трее **Open Settings** (файл `config.json`).
3. Вставьте ваш ключ в поле `"groq_api_key": "gsk_..."`.
4. Сохраните файл. (Также поддерживается переменная окружения `GROQ_API_KEY`).

---

## 🚀 6. Автозагрузка и Punto Switcher

* **Автозагрузка:** В трее поставьте галочку **Autostart with Windows**, и приложение будет тихо запускаться вместе с Windows.
* **Совместимость с Punto Switcher:** Вставка текста происходит атомарно через системный буфер (`Ctrl+V`), что полностью предотвращает ложные переключения раскладки Punto Switcher.
