🎙️ GIN-Voice [v015]

Быстрый голосовой ввод нейросетью Whisper Large v3 для Windows 10/11

1
Получите бесплатный ключ Groq API

Для мгновенного распознавания речи за 0.3 секунды программа использует движок Groq Whisper. Он полностью бесплатен (дает 7 000 секунд аудио в день бесплатно).

🌐 Открыть страницу Groq API Keys ↗
  • Войдите через аккаунт Google или GitHub;
  • Нажмите синюю кнопку «Create API Key»;
  • Скопируйте ключ (он начинается на gsk_...).
2
Вставьте ключ в окно программы

Вставьте скопированный ключ в появившееся окно настройки GIN-Voice и нажмите «Save & Activate».

Если окно уже закрыто: нажмите правой кнопкой мыши по значку микрофона у часов $\rightarrow$ Open Settings (config.json) и вставьте ключ в строку:

"groq_api_key": "gsk_ваш_скопированный_ключ"
3
Как пользоваться (всего 1 клавиша)
  • Поставьте курсор в любое место (браузер, блокнот, чат, Antigravity, Telegram).
  • Нажмите клавишу F4 — прозвучит короткий высокий сигнал (запись началась).
  • Продиктуйте нужный текст.
  • Нажмите F4 повторно — прозвучит сигнал, и текст мгновенно напечатается у курсора!
★
Языки и персональный словарь

Управление в трее у часов (правый клик по микрофону):

  • Выбор языков: По умолчанию включен English. Вы можете сразу отметить Czech и Russian для одновременной смешанной речи.
  • Проекты: Программа автоматически переводит произнесенные фразы в канонические названия: GIN-TV, GIN-Cinema, GIN-NetScan, GIN-VPN, GIN-Chat, GIN-Voice, Secret_Privat, ORACLE_157.
  • Автозагрузка: Поставьте галочку Autostart with Windows, чтобы программа работала незаметно в фоне.
