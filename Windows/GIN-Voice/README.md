## 🎯 What's New in v024
* **Live Interactive Hotkey Recorder:** Easily capture combinations (e.g. `Ctrl + Shift + S`, `Alt + ~`) directly by pressing them in settings instead of manual typing.
* **New Default Zero-Conflict Hotkey `Alt + ~` (Alt + ё):** Perfectly accessible with one left hand, completely unassigned and conflict-free across Cent Browser, Brave, Chrome, Antigravity IDE, and Windows.
* **Extended Keyboard Keys (F13–F24) & Multimedia Keys:** Full support for extended function keyboards, media keys, and full Win/Alt/Ctrl/Shift modifier combinations.
* **Widened Settings Input Field (170px):** Beautiful UI alignment with separate Record button for instant key assignment.
