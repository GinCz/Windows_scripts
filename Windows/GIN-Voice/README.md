# 🎙️ GIN-Voice: Автономный голосовой ввод и AI-распознавание речи (v039)

> **Владелец:** Владимир Буланцев ([GinCz ↗](https://github.com/GinCz))  
> **Репозиторий исходников (Приватный):** [Secret_Privat / Windows / GIN-Voice ↗](https://github.com/GinCz/Secret_Privat/tree/main/Windows/GIN-Voice)  
> **Публичный релизный каталог:** [Windows_scripts / GIN-Voice ↗](https://github.com/GinCz/Windows_scripts/tree/main/Windows/GIN-Voice)

## 🎯 1. Описание и назначение проекта

**GIN-Voice** — это сверхбыстрый, нативный инструмент фонового голосового ввода для Windows, созданный для системных администраторов, DevOps-инженеров, программистов и переводчиков. 

Приложение работает поверх Win32 API и перехватывает глобальную горячую клавишу **`[ F4 ]`** на аппаратном уровне. Нажатие `F4` активирует запись микрофона с отображением компактной стильной плашки HUD вверху экрана. Повторное нажатие `F4` мгновенно транскрибирует речь через облачный чип Groq LPU (скорость обработки ~0.2-0.3 секунды) и **вставляет распознанный текст прямо в то место, где установлен текстовый курсор** (в терминал PowerShell/Bash, браузеры Cent/Brave/Chrome, редакторы кода VS Code / JetBrains, IDE Antigravity, Telegram, WhatsApp и т.д.).

## ⚡ 2. Ключевые возможности и архитектура

1. **Мгновенная диктовка (0.15–0.30 сек):**
   - Прямой событийный захват звука через Win32 Multimedia API (`waveInOpen`, `CALLBACK_EVENT`).
   - Буферизация 16 кГц PCM в оперативной памяти без записи промежуточных WAV-файлов на диск (Zero Disk I/O).
2. **Интеллектуальная мультиязычность и Code-Switching (CS / EN / RU):**
   - Устранена фундаментальная проблема Whisper: когда пользователь говорит на нескольких языках подряд в одном предложении, стандартный Whisper жестко фиксируется на первом языке (например, русском) и фонетически транслитерирует чешские слова кириллицей (*«Ахой, як се маш?»*).
   - Внедрен AI-нормализатор на базе сверхбыстрой модели `qwen/qwen3.8-27b` (Groq LPU, задержка ~150 мс), который автоматически восстанавливает оригинальную чешскую латиницу и диакритику (*«Ahoj, jak se máš? Dobře, mám se dobře»*), не искажая русский текст.
   - Динамический кондиционирующий промпт (`prompt`) в API Whisper при мультиязычном режиме запрещает автоперевод английских и чешских фраз на русский.
3. **Абсолютная надежность и защита от зависаний (Anti-Deadlock Lock-Free Engine v032):**
   - Привязка главного потока через `runtime.LockOSThread()` исключает сбои очереди оконных сообщений Win32 при переключениях планировщика Go.
   - Состояние записи переведено на атомарный флаг `isRecording atomic.Bool`. Чтение состояния в контекстном меню трея (`showContextMenu()`) выполняется на 100% без мьютексов (Lock-Free), гарантируя мгновенный отклик правой кнопки мыши даже при тяжелой нагрузке.
   - Корректный сброс аудиодрайвера через `procSetEvent` и канал завершения `captureDoneChan`.
4. **Защита длинной речи (Speech Chunking VAD v033):**
   - Автоматическая разбивка длинных надиктовок на смысловые фрагменты по естественным паузам тишины.
5. **Фильтр хвостовых галлюцинаций (Extended Channel Outro Guard v034):**
   - Полное отсечение паразитных фраз Whisper датасета YouTube/соцсетей («Добро пожаловать в наш канал!», «Подписывайтесь на наш канал», «Ставьте лайки»).
6. **Кастомизируемый интерфейс HUD (WYSIWYG Fonts):**
   - Плавающий стильный киберпанк-оверлей Slate Gray (`#22272E`) с живой индикацией статуса (Запись, Обработка, Вставка).
   - Выбор любого установленного шрифта Windows (Comfortaa, Segoe UI, Bahnschrift, Consolas, Georgia, Arial и др.) с живым интерактивным предпросмотром.
7. **Персональный обучаемый словарь (`dictionary.json`):**
   - Мгновенная замена разговорных терминов и жаргона на точные идентификаторы, имена серверов и репозиториев (например, *«джин войс»* ➔ `GIN-Voice`, *«секрет приват»* ➔ `Secret_Privat`).
   - Автоматическое сканирование папки базы знаний (`D:\AI\GitHub`).
8. **Автономность и саморазвертывание:**
   - Единственный бинарник `GIN-Voice.exe` сам определяет свое местоположение, копируется в `%LOCALAPPDATA%\GIN-Voice\`, создает ярлыки на Рабочем столе и регистрируется в реестре программ Windows.

## 🏗️ 3. Структура файлов проекта

```text
Secret_Privat/Windows/GIN-Voice/
├── build.sh                  # Скрипт сборки на сервере
├── main.go                   # Основной исходный код приложения (Win32 GUI + Groq API)
├── go.mod                    # Манифест Go-модуля
├── rsrc_windows_amd64.syso   # Скомпилированные Windows PE-ресурсы (иконка, манифест)
├── app.ico                   # Основная иконка приложения (микрофон в синем круге)
├── app_rec.ico               # Иконка активной записи (микрофон в красном круге)
├── app.manifest              # Windows DPI-Awareness манифест
├── app.rc                    # Файл описания ресурсов RC
├── cmd/
│   └── uninstall/
│       └── main.go           # Исходный код фирменного деинсталлятора Uninstall.exe
├── config.json               # Шаблон конфигурации (хоткей F4, шрифты, языки)
├── dictionary.json           # Пользовательский словарь терминов
├── version.json              # Метаданные версии проекта для автообновления
├── version.txt               # Номер текущей версии (v038)
├── setup_guide.html          # Встроенное иллюстрированное руководство пользователя
├── icons_showcase.html       # Витрина вариантов иконок
├── uninstall.bat             # Скрипт удаления CMD
├── uninstall.ps1             # Скрипт удаления PowerShell
├── Uninstall.exe             # Скомпилированный бинарник деинсталлятора
├── CHANGELOG.md              # Полный журнал изменений всех версий (v001 - v038)
├── README.md                 # Документация проекта (этот файл)
├── GIN-Voice.exe             # Скомпилированный исполняемый файл последней версии
└── GIN-Voice_Setup_v038.exe  # Именованный установщик последней версии
```

## 🛠️ 4. Сборка проекта

Сборка бинарников под Windows выполняется командой:
```bash
GOOS=windows GOARCH=amd64 go build -ldflags="-H windowsgui -s -w" -o GIN-Voice.exe .
cp GIN-Voice.exe GIN-Voice_Setup_v038.exe
```
