## [v006] — 2026-11-08
- **Корневая причина найдена:** применение DNS и «Обновить» выполнялись в `[ThreadPool]::QueueUserWorkItem` — у PowerShell-скриптблоков в пуле потоков нет runspace, код молча не выполнялся (DNS не писался, «Обновить» закрывало программу).
- Теперь всё на UI-потоке с живой перерисовкой. DNS пишется в реестр `Tcpip\Parameters\Interfaces\{GUID}\NameServer` (ровно то, что показывает окно IPv4) + WMI + netsh validate=no + NetTCPIP; затем проверка обратным чтением. При ошибке — красная строка, окно не закрывается, лог `%TEMP%\GIN-DNS-Switch.log`.
- **Hotfix 04e619a (UTF-8 BOM Clean):** устранена критическая ошибка `CommandNotFoundException` («Имя "#" не распознано»). На 647-й строке перед комментарием `#` случайно затесался невидимый UTF-8 BOM (`\xef\xbb\xbf`), из-за чего `Invoke-Expression` парсил его как имя команды. Все скрытые BOM-байты полностью вычищены из исходников, инсталлятор начисто пересобран на Go и залит на Рабочий стол.
- Инсталлятор: `GIN-DNS-Switch_v006_Setup.exe`.

## [v004] — 2026-11-08
- **Статус:** 🟢 Релиз готов (v004 Critical Reliability & Architecture Release)
- **Инициатор задачи:** Владимир (исправление применения DNS на активном USB/Ethernet адаптере, переработка деинсталлятора по образцу GIN-Wallpaper/GIN-VPN, умная кнопка обновления с проверкой версии без закрытия, удаление дублирующего Cloudflare 1.1.1.1, обязательная версия в названии файла инсталлятора `GIN-DNS-Switch_v004_Setup.exe`).
- **Архитектура и ключевые исправления:**
  1. **Тройной движок применения DNS (Triple-Engine Architecture):**
     - Ранее при асинхронном запуске через raw ThreadPool cmdlets NetTCPIP могли терять контекст сессии или права.
     - Внедрён мощный 3-уровневый алгоритм применения:
       1) **WMI `Win32_NetworkAdapterConfiguration.SetDNSServerSearchOrder`** — универсальный стандарт Windows, 100% гарантированно меняет DNS на Realtek USB GbE, PCI и Wi-Fi сетевых картах.
       2) **NetTCPIP `Set-DnsClientServerAddress`** — обновляет стек современного сетевого профиля Windows.
       3) **`netsh interface ipv4 set dnsservers`** — прямой консольный байнд на активные сетевые интерфейсы.
     - В шаге 1 теперь явно выводится имя перенастроенного сетевого адаптера: `[✓] Сетевые адаптеры успешно настроены (Realtek USB/Ethernet)`.
  2. **Встроенный контроль прав Администратора (In-Process UAC Check):**
     - Внутри PowerShell добавлен строгий `WindowsPrincipal.IsInRole(Administrator)`. При отсутствии прав мгновенно перезапускается с `-Verb RunAs`.
  3. **Умная кнопка «Обновить»:**
     - Опрашивает `version.json` на GitHub.
     - Если версия уже актуальна (`v004`): **программа НЕ закрывается**, загорается яркая зелёная галочка `✔ У вас последняя версия (v004)`, звучит одиночный мягкий колокольчик, через 3 секунды кнопка возвращается в исходное состояние.
     - Если на GitHub есть более свежая версия: скачивает код, проигрывает фирменные **«два булька»**, пишет `✔ Обновлено!` и тихо перезапускает скрипт.
  4. **Нативный деинсталлятор `Uninstall.exe` (по стандарту GIN-Wallpaper):**
     - Написан на Go и скомпилирован в бинарник `Uninstall.exe` (1.6 MB).
     - При запуске копирует себя в `%TEMP%`, мгновенно снимает блокировку с папки `C:\Program Files\GIN-DNS-Switch\`, удаляет все ключи реестра (`HKLM` и `HKCU`), чистит ярлыки с Рабочего стола и меню «Пуск», начисто удаляет папку программы и самоудаляется.
  5. **Консолидация профилей:**
     - Убран отдельный 7-й пункт Cloudflare 1.1.1.1.
     - Остались 6 идеальных профилей:
       1) 🟢 **AdGuard DNS** (`94.140.14.14` • `94.140.15.15`) — Без рекламы
       2) 🔵 **Google + Cloudflare** (`8.8.8.8` • `1.1.1.1`) — Скорость, ТВ и банки
       3) 🔴 **DNS провайдера** — Чистый DHCP / Роутер
       4) 🟡 **Яндекс.DNS** (`77.88.8.8` • `77.88.8.1`) — Россия, Госуслуги, Сбер, сертификаты Минцифры
       5) 🟣 **Quad9 Security** (`9.9.9.9` • `149.112.112.112`) — Антивирус и фишинг
       6) 🌸 **Семейный DNS** (`94.140.14.15` • `94.140.15.16`) — Детский режим 18+
  6. **Стандарт именования инсталлятора с версией:**
     - Файл назван строго с версией: `GIN-DNS-Switch_v004_Setup.exe`.
     - Залит в Облако MEGA на Рабочий стол: `MEGA/DOCS/desktop/GIN-DNS-Switch_v004_Setup.exe`.
     - Старые неверсионные файлы на Рабочем столе удалены.
