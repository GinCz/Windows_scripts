- **Статус:** 🟢 Релиз готов (Initial Turnkey Release)

- **Архитектура:**
  - Автономный Polyglot Batch/PowerShell XAML (WPF) лаунчер с чистым темным интерфейсом.
  - Нативный 64-битный Windows GUI инсталлятор `GIN-DNS-Switch_Setup.exe` (1.7 MB, Go + MinGW) со встроенными ресурсами и автоматической тихой установкой за 1 секунду.
  - Установка в `C:\Program Files\GIN-DNS-Switch\` через `GIN-DNS-Switch_Setup.exe` или `Setup.cmd`.
  - Дизайнерская многослойная векторная иконка `app.ico` (256x256 -> 16x16, неоновый щит AdGuard + сеть DNS + молния скорости).
  - Автосоздание ярлыков на Рабочем столе и в меню «Пуск».
  - Выгрузка готового установщика на Рабочий стол Владимира в облаке MEGA: `MEGA/DOCS/desktop/GIN-DNS-Switch_Setup.exe` и в утилиты: `MEGA/WIN-FLASH/Util-WINDOWS/GIN-DNS-Switch_Setup.exe`.
  - Поддержка 4 ключевых профилей:
    1. `🛡️ AdGuard DNS (Без рекламы)` — `94.140.14.14`, `94.140.15.15` (IPv6: `2a10:50c0::ad1:ff`, `2a10:50c0::ad2:ff`).
    2. `📺 Чистый роутер / DHCP (ТВ и Стриминг)` — чистый автоматический DNS шлюза (100% совместимость с Android TV, Google Cast, CentBrowser, Chrome, банками).
    3. `🔴 DNS провайдера (Direct ISP)` — прямой шлюз провайдера.
    4. `⚡ Google + Cloudflare (Макс. скорость)` — `8.8.8.8` (Primary) + `1.1.1.1` (Secondary).
  - Двухэтапная верификация выполнения с визуальными зелеными галочками:
    - `[✓] Сетевой адаптер успешно перенастроен`
    - `[✓] Кэш сопоставителя DNS очищен (Flush DNS)`
  - Автоматический 3-секундный таймер обратного отсчета с полным завершением процесса (`Exit(0)`), 0 байт остаточного фона в RAM.
  - Мультиязычность: русский (RU), английский (EN), чешский (CS).
