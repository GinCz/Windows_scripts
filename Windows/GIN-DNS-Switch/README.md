## 📖 Описание

**GIN-DNS-Switch** — это ультра-легковесный автономный менеджер профилей DNS для Windows 7 / 8 / 10 / 11 с современным графическим интерфейсом (WPF) в тёмном стиле.

Утилита разработана для решения проблемы, когда фильтрующие DNS (например, AdGuard) блокируют трансляцию видео с Google Chrome / CentBrowser на телевизоры Android TV по локальной сети, а также вызывают сбои при авторизации в интернет-банках и публичных сетях Wi-Fi.

С **GIN-DNS-Switch** переключение между блокировкой рекламы и чистым режимом для стриминга занимает **ровно 1 клик** прямо с Рабочего стола!

---

## ✨ Основные возможности и профили

1. 🛡️ **AdGuard DNS (Без рекламы / No Ads):**
   - **IPv4:** `94.140.14.14`, `94.140.15.15`
   - **IPv6:** `2a10:50c0::ad1:ff`, `2a10:50c0::ad2:ff`
   - Блокировка баннеров, видеорекламы, спама, трекеров и фишинговых сайтов на уровне DNS.
2. 📺 **Чистый роутер / DHCP (ТВ и Стриминг / Pure DHCP):**
   - Автоматический DNS от шлюза роутера.
   - **100% стабильность Google Cast**, трансляции вкладок из Chrome / CentBrowser на Android TV, корректная работа интернет-банкинга и локальной сети.
3. 🔴 **DNS провайдера (Direct ISP):**
   - Прямой сброс сторонних DNS, полный доступ к локальным сервисам интернет-провайдера.
4. ⚡ **Google + Cloudflare (Макс. скорость):**
   - **Primary:** `8.8.8.8` (Google)
   - **Secondary:** `1.1.1.1` (Cloudflare)
   - Ультра-быстрый пинг, отсутствие цензуры провайдера, телевизор и трансляции работают отлично.

## ⚡ Особенности работы

- **Двухэтапная верификация с галочками:**
  1. `[✓] Сетевой адаптер успешно перенастроен`
  2. `[✓] Кэш сопоставителя DNS очищен (Flush DNS)`
- **Автоматический выход (Zero RAM):**
  После применения настроек запускается 3-секундный таймер, окно закрывается и процесс **полностью выгружается из оперативной памяти**. Утилита не висит в фоне и не потребляет ресурсы системы!
- **Мультиязычность:** Полная поддержка трёх языков: **Русский (RU)**, **Английский (EN)**, **Чешский (CS)** с мгновенным переключением в шапке окна.

## 🚀 Установка

1. Скачайте папку проекта или запустите от имени Администратора:
   ```cmd
   Setup.cmd
   ```
2. Скрипт установит утилиту в `C:\Program Files\GIN-DNS-Switch\` и создаст ярлыки на **Рабочем столе** и в **меню «Пуск»**.

Для удаления достаточно запустить `Uninstall.cmd` (или удалить через «Установка и удаление программ» Windows).
