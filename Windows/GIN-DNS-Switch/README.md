## 📖 Описание

**GIN-DNS-Switch** — это ультра-легковесный автономный менеджер профилей DNS для Windows 7 / 8 / 10 / 11 с современным графическим интерфейсом (WPF) в тёмном стиле.

Утилита меняет настройки DNS **глобально на уровне сетевого адаптера (TCP/IP)**, что мгновенно влияет на абсолютно все программы в Windows (браузеры Chrome, CentBrowser, Edge, Telegram, Discord, Steam, игры и системные службы).

Переключение между профилями занимает **ровно 1 клик** прямо с Рабочего стола!

## ⚡ Особенности работы

- **Тихое автообновление по кнопке (с двумя бульками):**  
  При клике на `v00X (Обновить)` утилита сама тихо скачивает свежий код из официального GitHub RAW, проигрывает фирменные **«два булька»** (`Asterisk Sound`), обновляет файлы в `Program Files` и перезапускается без лишних движений.
- **Двухэтапная верификация с галочками:**
  1. `[✓] Сетевой адаптер успешно перенастроен`
  2. `[✓] Кэш сопоставителя DNS очищен (Flush DNS)`
- **Автоматический выход (Zero RAM):**
  После применения настроек запускается 3-секундный таймер, окно закрывается и процесс **полностью выгружается из оперативной памяти** (0 байт в фоне).
- **Мультиязычность:** Русский (RU), Английский (EN), Чешский (CS).
