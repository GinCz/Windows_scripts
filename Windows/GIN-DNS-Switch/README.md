## 📖 Описание

**GIN-DNS-Switch** — это ультра-легковесный автономный менеджер профилей DNS для Windows 7 / 8 / 10 / 11 с современным графическим интерфейсом (WPF) в тёмном стиле.

Утилита меняет настройки DNS **глобально на уровне сетевого адаптера (TCP/IP)** через тройной стек (WMI + NetTCPIP + Netsh), гарантируя 100% срабатывание на любых сетевых картах (Realtek USB GbE, PCI, Wi-Fi).

Переключение между профилями занимает **ровно 1 клик** прямо с Рабочего стола!

## ⚡ Особенности работы

- **Тройной стек применения DNS:** WMI (`Win32_NetworkAdapterConfiguration`) + NetTCPIP (`Set-DnsClientServerAddress`) + `netsh interface ipv4 set dnsservers`.
- **Умная кнопка обновления:** При нажатии проверяет версию. Если версия уже последняя — выводит зелёную галочку `✔ У вас последняя версия (v004)` и НЕ закрывает программу.
- **Нативный деинсталлятор `Uninstall.exe`:** Скомпилирован на Go по стандарту `GIN-Wallpaper`. Копирует себя в `%TEMP%`, снимает локи, чисто удаляет все файлы, ярлыки и реестр.
- **Двухэтапная верификация с галочками и таймером выхода (Zero RAM):** 0 байт остаточного фона.
