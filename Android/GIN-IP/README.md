## 🌟 Key Features

* **⚡ Instant IP Audit:** Reveals public IPv4/IPv6, ISP provider name, country, city, and ASN.
* **📶 Local Wi-Fi & Gateway Diagnostics:** Displays internal IP, subnet mask, gateway IP, and link speed.
* **⏱️ Latency Benchmarks:** Multi-threaded ping tests to global DNS resolvers (1.1.1.1, 8.8.8.8, 9.9.9.9).
* **📋 1-Tap Copy:** Copy IP or full diagnostic report directly to clipboard.
